# Wolio Glossary

- **Package identity:** The canonical repository path of a package, such as `github.com/wolio-community/http`.
- **Source hash:** A cryptographic digest of the resolved package source.
- **Lockfile:** The exact dependency resolution recorded for a reproducible build.
- **Contract:** The machine-readable boundary describing inputs, outputs, effects, errors, and invariants.
- **WTP:** Wolio Tool Protocol.
- **OPEN:** A deliberately undecided design point that agents must not invent.
